# Сайт Екатерины Крайнюк

- Принципы: https://app.notion.com/p/gorokhovatsky/3a6777056402808bb79df09beedc4161
- Обычные HTML, CSS и JavaScript. Не добавлять фреймворк, сборщик или зависимости без необходимости и запроса пользователя.
- GitHub Pages публикует `main`, корень репозитория. Адрес: https://anton-gorokhovatsky.github.io/ekaterinakrainiuk/
- Основные материалы: сайт Кати на Тильде и её Instagram. Источники и границы переноса — в `docs/content-sources.md`.
- Не придумывать достижения, отзывы, квалификации, цены и расписание. Прямые цитаты сохранять буквально.
- Все фотографии и шрифты хранятся локально. Лицензии шрифтов должны оставаться в репозитории.
- Содержание, ссылки и раскрывающиеся блоки должны работать без JavaScript. Скрипты улучшают мобильную навигацию и позволяют сохранять выбор темы; системная тема работает и без JavaScript.
- Перед публикацией: `python3 scripts/check_static.py`, `node --check script.js`, `node --check theme.js`, `node --test scripts/theme.test.cjs`, `git diff --check`, визуальный просмотр обеих тем на широком и узком экране, проверка клавиатуры и состояния меню. После публикации проверить SHA, GitHub Pages и публичный сайт.
- Визуально одобренную пользователем композицию сохранять; последующие изменения делать в согласованных границах.
