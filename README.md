# Екатерина Крайнюк

Личный сайт тренера по циклическим видам спорта.

**Сайт:** https://anton-gorokhovatsky.github.io/ekaterinakrainiuk/

Чистые HTML, CSS и JavaScript. Без npm, сборки, внешних виджетов и обязательных клиентских библиотек.

## Структура

- `index.html` — тексты, услуги, цены, отзывы и контакты.
- У семи форматов видны краткое назначение и цена до раскрытия; контакты подсказывают содержание первого сообщения. Условия работы сохраняются по источникам, порядок знакомства не придумывается.
- `styles.css` — новая композиция и адаптивность; `tarot.css` — самостоятельное оформление одобренной игры.
- `themes.css` — светлая и тёмная палитры, в том числе системная тема без JavaScript.
- `script.js` — мобильное меню и открытие спортивной истории по ссылке; `theme.js` — выбор темы до первого отображения страницы и сохранение предпочтения.
- `assets/images/` — локальные WebP-фотографии Кати и её спортсменов.
- В обложке `nice-friends` и `nice-run` имеют версии шириной 450, 800 и 1200 px; браузер выбирает их через `srcset`. Приоритетная загрузка оставлена первой фотографии, остальные загружаются по мере приближения к экрану.
- `assets/fonts/` — локальные Golos Text для основного набора и Ambidexter для трёх слов на рубашках карт, оба с лицензиями OFL. Для отсутствующего в основном поднаборе знака ₽ загружается отдельный WOFF2 на 888 байт. Файлы прежних шрифтов сохранены для архивных материалов, но сайт их не загружает. Источники и состав — в `assets/fonts/README.md`.
- `assets/icons/` — пиктограммы Tabler Outline и их MIT-лицензия.
- `assets/favicon.svg` — веер из трёх карт в цветах сайта. PNG 16 и 32 px служат запасными вариантами, 180 px — иконкой домашнего экрана.
- `docs/content-sources.md` — источники контента и редакционные решения.
- [docs/ux-rules.md](docs/ux-rules.md) — 32 обязательных правила UX для проектирования, реализации и приёмки; закреплены в `AGENTS.md`.
- [docs/nng-sources.md](docs/nng-sources.md) — 37 первоисточников NN/g, пояснения W3C и границы применения рекомендаций.
- [docs/ux-review-checklist.md](docs/ux-review-checklist.md) — проверка конкретной правки, сценарии и требования к свидетельствам результата.
- [docs/design-direction.md](docs/design-direction.md) — принятые решения композиции, типографики, материалов и взаимодействия.
- `docs/usability-checks.md` — изменения выбора формата, проверки Safari и границы приёмки доступности.
- `docs/image-sources.json` — соответствие фотографий оригиналам.
- `assets/images/share-card-v5.png` — карточка для шера, 1200 × 630: приглашение «Ну что, погнали?», Golos Text и три фотографии с обложки. Ссылка и описание изображения заданы в Open Graph и Twitter Card в `index.html`.

По умолчанию тема следует настройке системы и меняется вместе с ней. В шапке (на узком экране — в меню) можно выбрать «Как в системе», «Светлая» или «Тёмная». Ручной выбор хранится в localStorage под ключом `ekaterinakrainiuk-theme` и применяется также на странице 404. Если хранилище недоступно, переключатель продолжает работать в текущем посещении.

## Локальный просмотр

Из папки репозитория:

```sh
python3 -m http.server 4177 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4177/.

## Проверка и публикация

```sh
python3 scripts/check_static.py
node --check script.js
node --check theme.js
node --check video.js
node --check tarot.js
node --check daylight.js
node --test scripts/*.test.cjs
git diff --check
```

GitHub Pages настроен на ветку `main`, папку `/`. `.nojekyll` отключает обработку Jekyll. После отправки изменений GitHub публикует статические файлы. Проверка `Static checks` дополнительно запускается в Actions; перед отправкой нужно также просмотреть изменённый экран в браузере и пройти применимые пункты [UX-чеклиста](docs/ux-review-checklist.md). Автоматические проверки не заменяют просмотр композиции и взаимодействия.

Фотографии, отзывы и цены перенесены из предоставленных источников. При обновлении услуг меняйте текст непосредственно в HTML. Дополнительной синхронизации с Тильдой или Instagram нет.

Для смены адреса обновите canonical, Open Graph URL, `sitemap.xml`, `robots.txt` и ссылку на главную в `404.html`.

## Индексация

Индексация временно отключена: в `index.html` установлен `<meta name="robots" content="noindex">`. Сайт остаётся доступным по ссылке. Обход поисковикам разрешён, чтобы они могли прочитать запрет; блокировать его через `Disallow` не нужно. Подробнее — в [документации Google](https://developers.google.com/search/docs/crawling-indexing/block-indexing).

Чтобы снова разрешить индексацию, удалите этот метатег из `index.html` и опубликуйте изменение. На странице `404.html` запрет должен остаться.

## Живая среда и игра

- `daylight.js` показывает время Москвы и почасовой прогноз MET Norway (Locationforecast 2.0), восход и закат (Sunrise 3.0). Это прогноз на текущий час, не показания ближайшей метеостанции. Матовый материал берёт цвет из общего фона страницы, без дополнительного оттенка шапки; облачность меняет его плотность. Ветер вызывает один короткий порыв при появлении колоды; наведение, касание, фокус и системное уменьшение движения останавливают эффект. Светлая, тёмная и системная темы независимы от погоды. Геолокация пользователя не запрашивается. Москва подписана как город очных тренировок, не текущее местонахождение Кати.
- Оттенок света плавно меняется между ночью, восходом, днём и закатом по московским астрономическим данным. Общий фон, стекло, погодная панель, четыре спортивные главы, синий блок о Кате, розовый раздел Таро, светлые стороны карт и лаймовые акценты следуют одному ходу времени. У каждого основного цвета есть утренняя, дневная, вечерняя и ночная вариации; облачность пропорционально приглушает их. Общие CSS-переменные связывают разделы с их ховерами, кнопками и пиктограммами. При отсутствии свежих данных возвращаются исходные цвета. Выбор темы и фотографии сохраняются. Расчёт выполняется при существующем минутном обновлении, без дополнительных запросов и анимационного цикла.
- Данные MET Norway доступны по [CC BY 4.0](https://docs.api.met.no/doc/License.html), включая коммерческое использование. Источник, лицензия и округление значений указаны в погодном блоке. Небольшой сайт использует разрешённые [простые CORS-запросы с Origin](https://docs.api.met.no/doc/TermsOfService.html), без ключей и нестандартных заголовков. Если суммарный трафик приблизится к 20 запросам в секунду, нужен общий кеширующий сервер; такой объём требует отдельного согласования с MET Norway.
- Прогноз кешируется в sessionStorage минимум на 30 минут и не запрашивается повторно до `Expires`; браузер также использует HTTP-кеш. Восход и закат сохраняются для конкретных дат. Запросы отменяются через 8 секунд и не начинаются в скрытой вкладке; после 403/429 действует увеличенная пауза. Модели старше 12 часов, отсутствующий прогноз на текущий час и неполные ответы не показываются. При сбое остаются московские часы и сообщение об отсутствии свежих данных, материал страницы возвращается к базовому. Сеть не нужна для содержания сайта.
- `tarot.js` — вымышленное спортивное Таро: 7 дисциплин, по 4 совместимых формата и 8 предсказаний. Новый расклад меняет дисциплину и знак. Карты открываются отдельно или вместе, на телефоне листаются, а при reduced motion переворачиваются без анимации. Без JavaScript показан статический пример.
- Блок Strava — **датированная редакционная запись**, а не автоматически обновляемая лента. Для обновления заменить дату, результат, заголовок и URL активности в `.strava-note` файла `index.html`. Текущий источник: https://www.strava.com/activities/20332347814 — 26 сентября 2026, 10,00 км, 42:33, 4:15/км. Ключей API, токенов и стороннего embed-скрипта нет.
