# Екатерина Крайнюк

Личный сайт тренера по циклическим видам спорта.

**Сайт:** https://anton-gorokhovatsky.github.io/ekaterinakrainiuk/

Чистые HTML, CSS и JavaScript. Без npm, сборки, внешних виджетов и обязательных клиентских библиотек.

## Структура

- `index.html` — тексты, услуги, цены, отзывы и контакты.
- `styles.css` — оформление и адаптивность; основные цвета и отступы в `:root`.
- `script.js` — мобильное меню. Остальной сайт работает без JavaScript.
- `assets/images/` — локальные WebP-фотографии Кати и её спортсменов.
- `assets/fonts/` — Golos Text и Oswald с лицензиями OFL.
- `docs/content-sources.md` — источники контента и редакционные решения.
- `docs/image-sources.json` — соответствие фотографий оригиналам.

## Локальный просмотр

Из папки репозитория:

```sh
python3 -m http.server 4177 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4177/.

## Проверка и публикация

```sh
python3 scripts/check_static.py
node --check script.js
git diff --check
```

GitHub Pages настроен на ветку `main`, папку `/`. `.nojekyll` отключает обработку Jekyll. После отправки изменений GitHub публикует статические файлы. Проверка `Static checks` дополнительно запускается в Actions; перед отправкой нужно также просмотреть изменённый экран в браузере.

Фотографии, отзывы и цены перенесены из предоставленных источников. При обновлении услуг меняйте текст непосредственно в HTML. Дополнительной синхронизации с Тильдой или Instagram нет.

Для смены адреса обновите canonical, Open Graph URL, `sitemap.xml`, `robots.txt` и ссылку на главную в `404.html`.
